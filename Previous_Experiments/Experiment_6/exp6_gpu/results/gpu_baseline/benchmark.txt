The NVIDIA RTC library that hashcat compiles its kernels with comes with the CUDA Toolkit.
Install the Windows build of it from https://developer.nvidia.com/cuda-downloads, choosing
Windows and the version of it you are on. The GPU driver on its own does not carry it.

Linux CUDA Toolkit installed inside it. No NVIDIA GPU driver is installed inside WSL2 itself.
