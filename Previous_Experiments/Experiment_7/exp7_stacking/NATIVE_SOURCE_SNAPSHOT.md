# Reproducing the native dependencies

The uploaded Lyra and Catena working source trees, including the modified Catena header and its original `.bak`, are retained. Nested `.git` object databases and compiled `.so` files were excluded. `native/source_revisions.txt` records the original upstream commits (Lyra first, Catena second). The original `setup_extra_linux.sh` is retained unchanged. It expects Git checkouts and will attempt to clone when `.git` is missing, so do not run it over these nonempty snapshots. To recreate the original build, use the preserved source snapshots and the compilation commands in that script, or clone the recorded commits in a fresh working directory and reproduce the preserved header modification before building. Run the original self-test before collecting measurements. No measurements were changed.
